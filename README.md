# 图书管理系统 (Library Management System)

一个用 C 语言实现的图书管理系统,基于**带头结点的单链表**存储数据,包含管理员/读者账号体系,以及图书的录入、查询、删除、借阅/归还功能。

## 功能特性

- **账号体系**:管理员注册登录、读者注册登录、游客访问
- **图书管理**:录入图书(ISBN 查重)、显示图书列表、按 ISBN 查找、删除图书(仅管理员)
- **借阅管理**:借书(检查是否在馆、记录借阅人)、还书(校验借阅人身份)
- **权限控制**:管理员可查看全部借阅情况及借阅者信息,读者只能借还书,游客仅可浏览

## 权限一览

| 功能 | 游客 | 读者 | 管理员 |
|------|:---:|:---:|:---:|
| 查看图书列表 | ✅ | ✅ | ✅ |
| 录入 / 删除图书 | ❌ | ❌ | ✅ |
| 借书 / 还书 | ❌ | ✅ | ✅ |
| 查看借阅者信息 | ❌ | ❌ | ✅ |

## 项目结构

| 文件 | 作用 |
|------|------|
| `main.c` | 程序入口 |
| `menu.c` / `menu.h` | 菜单界面与流程控制 |
| `book.h` | 图书结构体定义(含借阅状态 status / 借阅人 borrower) |
| `linklist.c` / `linklist.h` | 单链表操作:增、删、按 ISBN 查找 |
| `logIn.c` / `logIn.h` | 用户注册、登录、角色管理 |
| `borrow.c` / `borrow.h` | 借书、还书、借阅情况查看 |

## 编译运行

需要 gcc(Windows 建议 MinGW 环境):

```bash
gcc -o 程序.exe main.c menu.c linklist.c logIn.c borrow.c -static
./程序.exe
```

## 使用流程

1. 启动程序 → 注册一个**管理员**账号(或读者账号)
2. 管理员登录 → **录入图书**、查看借阅情况
3. 退出后,用**读者**账号登录 → 借书 / 还书
4. 游客访问只能查看图书列表,不能借书

## 说明
